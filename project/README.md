# Полный проект — всё вместе

Это объединённая версия: базовый проект + прикрепление файлов служебок к
закупкам + разбивка закупки на несколько филиалов + импорт плана из Excel.
Раньше это были три отдельных патча — теперь один консистентный набор файлов
поверх исходного репозитория.

## Важно про этот конкретный архив

Роут файлов служебок (`backend/src/routes/documents.js`) и volume в
`docker-compose.yml` в исходных материалах отсутствовали (архив с первой
частью, где это делалось, в этот раз не был приложен) — я восстановил их
по описанию и по тому, что ожидает фронтенд (`DocumentsModal.jsx`, `api.js`).
Логика та же (загрузка/список/скачивание/удаление, лимит 20 МБ, права:
загружать — admin/financier/branch_editor, удалять — admin/financier),
но **если у вас в реальной базе таблица `documents` уже существует с другими
названиями колонок** — перед деплоем сверьте её структуру (`\d documents`)
с тем, что использует `documents.js`:

```
entity_type, entity_id, file_name, stored_name, file_size, mime_type,
description, uploaded_by, uploaded_at
```

Если названия колонок отличаются — либо приведите таблицу к этому виду,
либо поправьте запросы в `documents.js` под вашу реальную структуру.

## 1. База данных

Выполните `MIGRATION-FULL.sql` в psql:

```
Containers → myapp_postgres → Console → /bin/bash → psql -U appuser -d appdb
```

Вставляйте блоки по одному. Все команды написаны через `IF NOT EXISTS` —
если что-то из этого у вас уже было применено раньше, повторный запуск
ничего не сломает и не удалит.

Что делает миграция:
- создаёт таблицу `documents` (если её ещё нет) — файлы служебок;
- делает `purchases.branch_id` необязательным и добавляет таблицу
  `purchase_branch_shares` — разбивка суммы закупки по филиалам.

## 2. Файлы проекта

Замените содержимое вашего репозитория целиком на содержимое папок
`backend/` и `frontend/` из этого архива (плюс `docker-compose.yml` в корне).
Ничего вручную сравнивать не нужно — это уже полный набор файлов со всеми
тремя частями внутри.

## 3. Пересборка

```
git add .
git commit -m "Объединение: файлы служебок + разбивка по филиалам + импорт Excel"
git push
```

В Portainer — **Pull and redeploy** для `backend` и `frontend` (обязательно
пересобрать: у backend новые зависимости `multer` и `xlsx`, у docker-compose —
новый volume `uploads_data`).

## 4. Что умеет система целиком

- Вход, светлая/тёмная тема, боковое меню с вкладками
- Главная — дашборд: суммы по кварталам, по филиалам, счётчик «ждут проверки»
- Филиалы — список, добавление, редактирование
- Годовой план / Кв. 1–4 — таблица закупок: фильтр, добавление, редактирование,
  перенос между кварталами, отмена
- Поиск по названию закупки, ОКПД2, филиалу
- Подсветка: закупка от филиала, которую центр ещё не проверял — жёлтая рамка;
  внеплановая — красная; отменённая — серая, зачёркнута
- **Файлы служебок**: кнопка «📎 файлы» у каждой закупки — список, загрузка,
  скачивание, удаление (удаление только admin/financier), лимит 20 МБ
- **Закупка на несколько филиалов**: в форме — список «Филиалы и суммы»
  вместо одного поля, кнопка «+ добавить филиал»; в таблице такая позиция
  показывает «N филиала(ов)» с расшифровкой
- **Импорт из Excel**: кнопка «Импорт из Excel» (admin/financier) — парсер
  под формат «План закупочных мероприятий», сам находит заголовки, квартал,
  склеивает многострочные закупки на несколько филиалов, сопоставляет
  «Потребители» с уже заведёнными филиалами по названию, после импорта
  показывает что создано / что не найдено / что пропущено
